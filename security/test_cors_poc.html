CORS Vulnerability Proof of Concept

Vulnerability Explanation

BEFORE FIX: The send-quote-request edge function used wide-open CORS headers from Supabase, allowing any origin to invoke the function. This could enable cross-origin attacks from malicious websites.

AFTER FIX: CORS is restricted to specific allowed origins (https://zapsitestudio.com and localhost for development). Cross-origin requests from unauthorized domains will be blocked by the browser.

Test 1: Authorized Origin (Localhost)

This test simulates a request from an authorized origin (localhost for development).

Test 2: Unauthorized Origin (Evil.com)

This test simulates a request from an unauthorized origin (a malicious website).

Test 3: Direct API Call (No Origin Header)

This test simulates a direct API call without an origin header (like from curl or a mobile app).
